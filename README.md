# C - ARRAYS

This repository contains my solutions to **ARRAYS** problems in the C programming language.

The purpose of this repository is to strengthen my understanding of arrays, improve logical thinking, and develop problem-solving skills by solving various arrays-based problems.

## Topics Covered

- Arrays
- Array declaration
- Sorting
- Searching Elements
  
## Sample Problems

- Read and print elements of an array
- Find the sum of all array elements
- Find the average of array elements
- Find the largest and smallest element
- Count even and odd elements
- Search for an element in an array
- Find duplicate elements in an array
- Find distinct elements in an array
- Reverse an array
- And many more...
